# 进阶 · 编队

> **读者：人。** 这是进阶功能：编队决定**带路条件能不能过**和**每场战斗油耗多少**。
> 只想选路线、看地图结构的话，[README](../README.md) 那三分钟就够用了。
> 先要有一份舰灵库（见 [进阶-舰灵库录入](进阶-舰灵库录入.md)），编队才有船可填。

## 一、编队是什么

一次出击要带**两个队伍**（各最多 6 艘）。编队面板里：

- **列表第一个位置就是旗舰** —— 「旗舰为 …」类条件数的是两个队伍的旗舰
- **指定哪一队是强队**（默认 1 队）：**BOSS 点必须由强队出战**，自动分配出战队伍时会守住这条
- **同一艘船不能编入两个队伍**（见文末的「唯一性」）

可以建多个编队，**当前选中的那个**参与条件判定和油耗计算；一个编队都没有时，页面会自动建一个空的。
「强队」是**每个编队各自记**的设置。

## 二、建编队与填船

1. 右侧「编队」页签 → 新建 / 选一个编队
2. 点队伍里的「+ 添加舰灵」打开**选船面板**：
   - 按**舰名搜索**（`拉菲` 能同时命中 `拉菲(DD-459)` 和 `拉菲·改(DD-724)`）
   - 按**舰种 / 国籍多选快筛**，可「只看收藏」
   - 每行显示 油耗 / 航速 供决策
   - **已在另一个队伍的船会标灰并注明「已在 N 队」，点不动**
3. 加进来的船按顺序排，**第一个就是旗舰**；每行有 `↑`「设为旗舰（移到首位）」按钮，点一下把它顶到队首

## 三、组队时怎么不迷路

舰灵上百艘之后，「找不到想要的船」是主要痛点，所以：

- **两队合并统计**：编队面板常驻显示合并后的 舰灵数 / 各舰种 / 各阵营 / 均速 / 索敌
- **带路条件实时对比**：把当前路线的条件拉过来逐条比对，并**算出差多少**
  （例如「舰队中 航母　需 3~12　当前 1　✗ 少 2」）。组队和判定在同一视野里，不用来回滚
- **收藏**：收藏的船在列表和选船面板里永远置顶，并写进导出的 `data/ships.js`（`fav` 字段）
- **一键清空某一队**：每个队伍标题右边（`N/6` 旁边）有「清空」，点一下只把**这一队**的舰灵全下，
  另一队和编队本身（名字、「强队」设置）都不动；这一队本来就是空的时候按钮是禁用的

## 四、均速值 / 索敌值的手动覆盖

地图条件 `舰队均速值<34` / `舰队索敌值≥800` 默认按两个假设算：

- 均速值 = 全部舰灵航速的**算术平均**
- 索敌值 = 全部舰灵索敌值的**和**

这两个假设**未经游戏数据验证**。所以编队面板里可以直接手填「舰队均速值 / 舰队索敌值」**覆盖**掉，
覆盖值会被同一套判定读到（条件行、覆盖规划都一样），改完**立刻**刷新，不用重开页面。

只要有一个舰灵没录航速 / 索敌，这两个条件就判 `? 未知` 而不是「不满足」——
避免把「缺数据」误报成「走不通」。修数据或手动覆盖之后就恢复正常 ✓ / ✗。

## 五、和覆盖规划的联动

「覆盖规划」里的 `用当前编队过滤条件` 开关，用的就是当前这个编队：

- 开启后，带路条件**明确不满足**的路线不参与规划，避免规划出走不了的方案
- **编队没填够时（每队不足 2 个舰灵）会自动跳过过滤** —— 空编队会让「至少 N 个」这类条件恒不满足，
  那是缺数据而不是条件不成立

## 六、唯一性：一艘船不能进两个队伍

同一艘船编入两个队伍**不只是违反游戏规则** —— 重复编入会让「两队合并」的舰种 / 阵营计数重复，
带路条件判定和油耗都会悄悄算错。所以增删都走 `FX.store`，由它守住这条不变量
（`tools/test_core.js` 里有对应用例锁着）。

## 七、编队存哪、怎么落盘

和舰灵库同一套三层机制（文件层 `data/fleets.js` / 私有层 `local/fleets.local.js` / 浏览器草稿），
合并语义也一样：**草稿优先、文件补充、墓碑挡删除**。落盘靠「导出 fleets.js」下载后覆盖回 `data/`
（想让编队不进 git 就覆盖 `local/fleets.local.js`）。细节见
[进阶-舰灵库录入 · 数据怎么存](进阶-舰灵库录入.md) 与 [local/README.md](../local/README.md)。
